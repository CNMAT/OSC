FruitJamOscuino

OSC over Web Serial for Adafruit Fruit Jam (RP2350B). Browser ↔ SLIP ↔ USB serial ↔ CircuitPython. Pair with code.py. No server, no dependencies.
Not connected
Args are typed automatically: 1 → int, 0.5 → float, anything else → string. Force a type with i: f: s:, or use bare T F N. bundle is ticked by default because code.py reads bundles, as do the stock Oscuino examples and the CNMAT Max patches.

Adafruit Fruit Jam. Two firmwares answer this page with the same address space: code.py under CircuitPython (extras/python/FruitJamOscuino/, copy boot.py + code.py to CIRCUITPY) and the hand-written examples/FruitJamOscuino sketch under arduino-pico (needs Adafruit NeoPixel, Adafruit TLV320 I2S and PicoDVI). /fj/b reads the three user buttons (1 = pressed), /fj/led drives the five NeoPixels (three ints = all, four = index first), /fj/beep plays a sine through the headphone/speaker codec, /fj/t puts text on the DVI output. The USB filter matches Adafruit's and Raspberry Pi's vendor ids to cover both firmwares' CDC identities.
