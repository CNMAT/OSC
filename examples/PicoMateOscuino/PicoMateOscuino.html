DeskPi PicoMate — every sensor, as an instrument

The board laid out as it physically is: modules down each side, the Pico dock and prototyping area in the middle. Each one is drawn as the thing it is — a compass needle for the magnetometer, a spirit level for the accelerometer, a thermometer and a hygrometer dial, a lamp for the colour sensor. Everything arrives in a single /pm message so the readings share one instant. Web Serial needs http://localhost.
