XIAO ESP32-C6 expansion board — OSC over USB serial

Drives the expansion board's OLED, buzzer and button from the browser over Web Serial. The screen below mirrors what was sent to the real panel. A WiFi twin of this sketch, XiaoC6ExpWiFi, speaks the same OSC vocabulary over UDP. Web Serial needs http://localhost — a file:// URL gets an empty port picker.
