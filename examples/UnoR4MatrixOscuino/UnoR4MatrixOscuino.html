UNO R4 WiFi — scrolling messages on the LED matrix over OSC

Type a message, send it as an OSC string, and watch the board's 12×8 matrix scroll it. The panel below is not a simulation: the sketch sends the exact 96 pixels it lit as an OSC blob on every scroll step, and this page draws those. Web Serial needs http://localhost — a file:// URL gets an empty port picker.
