UNO R4 WiFi — scrolling messages on the LED matrix over OSC

Type a message, send it as /display/text, and watch the board's 12×8 matrix scroll it. The panel below is not a simulation: the sketch sends the exact 96 pixels it lit as a /display/frame blob on every scroll step, and this page draws those. Web Serial needs http://localhost — a file:// URL gets an empty port picker.

Pause and Blank send /display/pause and /display/bl; the board echoes each, and the buttons follow the echo. The slider is the scroll step, not a stream rate — the /state bundle has its own /rate.

display is the /enq/display 12 8 line of the /enq bundle: present when the matrix driver started, absent when it failed. The sketch reports the driver, not the panel — it cannot tell a wired matrix from a bare RA4M1. scroll is the board's /diag line, shown verbatim.
This board's serial port is a real UART bridged to the host by an on-board ESP32-S3, not native USB — so both ends must agree on 115200 and there is no end-to-end USB flow control. See BOARDS.md.
