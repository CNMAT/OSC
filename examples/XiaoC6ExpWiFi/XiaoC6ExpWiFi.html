The same OLED, buzzer and button as the serial twin, reached over the network instead. A browser cannot send UDP, so this page POSTs the very same OSC packet bytes to the board over HTTP and the sketch feeds them to one shared handler — real OSC software talks to the same board on UDP port 8000 at the same time.
